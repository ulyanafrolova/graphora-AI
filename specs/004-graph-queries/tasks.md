# Tasks: Graph Queries

**Input**: Design documents from `specs/004-graph-queries/`

**Prerequisites**: plan.md, spec.md, research.md (R1–R12), data-model.md, contracts/queries-api.md,
contracts/answers.md, contracts/cli.md, quickstart.md

**Tests**: Required. Constitution VIII requires golden tests over the fixtures with hand-checked answers and a
repeated run with identical output; SC-001–SC-005 are checked by tests. Within each story, write the tests
first and confirm they fail before you implement.

**Organization**: Tasks are grouped by user story:

- US1 (P1): dependents and impact (with dependencies and the `graphora query` CLI);
- US2 (P1): cycles;
- US3 (P2): neighbors and key files;
- US4 (P3): barrel following.

Paths are relative to the repository root. Code lives in `backend/src/graphora/`, tests in `backend/tests/`.
Run commands from `backend/`. Do not edit any existing `expected.json`, `graph/model.py` or
`graph/serialize.py`. Golden files (`expected.json`, `queries.json`) are written by hand from reading the
fixture source, never generated by the tool. Keep comments minimal, in the style of the existing modules.

**Commits**: each phase ends with one commit and push (marked **Commit**), so the PR has 7 commits in total
(the spec/plan commit is the first). Run `make check` from the repository root before each commit.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies on incomplete tasks)
- **[Story]**: The user story the task belongs to (US1–US4)
